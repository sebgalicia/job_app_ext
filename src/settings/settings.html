      Automatic filling

      Optional help for application forms with multiple steps.

      When enabled, visible empty fields with a Medium or High match are filled when a step opens. The extension waits for you to press Next or Continue before checking the next step. It never submits the application. Review each step before continuing.

      When enabled, the extension selects a clear “Yes” or “I agree” response, signs explicit signature fields with your saved name, and fills dates for agreement fields with today’s local date. It types “yes” only when a prompt explicitly asks you to enter it. It never submits the application. Enable this only if you want these acknowledgments completed automatically.
